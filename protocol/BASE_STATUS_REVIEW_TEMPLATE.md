## 冻结前置条件

以下所有项目均需有数据表、原理图或台架测量证据；任一项未完成时，不得把字段写入 `robot_protocol.h`、STM32 固件或实机 ROS 2 传输代码。

- [ ] 左右电机与驱动器型号、电压、连续/峰值电流和故障输出已确认。
- [ ] 编码器为单相/AB 相、计数位置、CPR/PPR、齿轮比、计数方向和溢出策略已确认。
- [ ] 轮径和轮距有实测值及测量方法；不得沿用 Gazebo 名义值。
- [ ] 电池、BMS、欠压阈值和电压采样误差已确认。
- [ ] STM32 独立急停、命令超时、PWM 禁用和故障锁存行为已在未连接 ROS 2 时验证。
- [ ] UART/CAN 电平、波特率/仲裁率、终端电阻、连接器与掉线恢复语义已确认。
- [ ] `BaseStatus.msg` 映射、字节序、缩放、范围、无效值和版本升级策略已评审。
